# Wikipedia Search App

A simple web application built using **Flask** that allows users to search for information on Wikipedia and view a brief summary of the article. The app takes a user's search query, fetches the data from Wikipedia, and displays a concise summary of the result.

## 📋 Features

- **Search Wikipedia**: Enter a search term to retrieve a brief summary from Wikipedia.
- **Simple Interface**: Minimalist interface with a clean and easy-to-use form.
- **Instant Results**: Shows a 2-sentence summary for the search term.

## 🚀 Technologies Used

- **Python** (Flask Framework)
- **HTML** (Basic form for the user interface)
- **Wikipedia API** (To fetch the summary of articles)
